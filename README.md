# ACT FFXIV Emergency Update

## 日本語

FFXIVアップデート直後、公式のACT / FFXIV Plugin更新を待てない方向けの非公式Emergency Updateです。

### 使い方

このZIPの内容を、ACTの `Plugins` フォルダへ上書きしてください。

念のため、上書き前に現在のPluginsフォルダをバックアップしておくことをおすすめします。

### 注意

このファイルは非公式のEmergency Updateです。

FFXIVのアップデート内容によっては、すべての機能が正常に動作しない可能性があります。

元のバージョンは変更せず、新しいFFXIVで動作させるために必要な部分だけを更新しています。

公式版が更新されると、ACT起動時にいつも通り更新のお知らせが表示されます。

もしメンテナンス直後にこれが役に立ったと思ったら、ジュース1本奢ってもらえると嬉しいです！ 🧃

## English

This is an unofficial Emergency Update for users who want to use ACT / FFXIV Plugin immediately after an FFXIV update without waiting for the official update.

### Installation

Extract this ZIP and overwrite the files in your ACT `Plugins` folder.

It is recommended to make a backup of your current Plugins folder before overwriting the files.

### Notice

This is an unofficial Emergency Update.

Depending on the changes made in an FFXIV update, some features may not work correctly.

The original version is preserved, and only the parts required to work with the updated FFXIV client are changed.

When an official update becomes available, ACT will notify you about the update as usual when it starts.

If this helped you get back up and running right after maintenance, feel free to buy me a juice! 🧃
